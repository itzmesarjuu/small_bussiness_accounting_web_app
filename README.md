# 📊 LedgerLite — Small Business Accounting Web App

A modern, premium small business accounting web application built with vanilla HTML, CSS, and JavaScript. Features a stunning dark glassmorphism design with light theme support.

![LedgerLite Dashboard](https://img.shields.io/badge/LedgerLite-Accounting-6C5CE7?style=for-the-badge)

## ✨ Features

- **Dashboard** — KPI cards, revenue/expense charts, activity feed
- **Invoices** — Full CRUD with filtering, status badges, CSV export
- **Expenses** — Category tracking, payment method management
- **Clients** — Client cards with revenue analytics
- **Reports** — P&L summary, monthly trends, cash flow, top clients
- **Settings** — Theme toggle (dark/light), accent colors, currency (INR ₹)
- **Supabase** — Optional database backend for persistent data

## 🛠️ Tech Stack

- HTML5 / CSS3 / JavaScript (ES6+)
- Chart.js for interactive charts
- Supabase for database (optional)
- Netlify for hosting

## 🚀 Live Demo

Deployed on Netlify — accessible via single link.

## 📦 Setup

1. Clone the repo
2. Open `index.html` in browser (works offline with sample data)
3. To enable Supabase: edit `supabase.js` with your project credentials

## 🗄️ Supabase Setup

1. Create a project at [supabase.com](https://supabase.com)
2. Run `supabase-schema.sql` in the SQL Editor
3. Copy your Project URL and anon key into `supabase.js`
